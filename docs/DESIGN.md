# 个人站点：首页（兼导航页）+ 极简后台

一个「简洁 / 低文字密度 / 背景随时间变化」的个人站点首页，配一个只用 Python 标准库实现的零依赖后台。
首页最多四屏，靠下滑依次展开；哪一屏存在由配置决定。

| 屏 | 内容 | 出现条件 |
| --- | --- | --- |
| 1 | 头像、姓名、身份、一句话、状态、社交图标 | 始终 |
| 2 | 图标磁贴导航（博客 / 项目 / 相册 / 关于 / 归档 / 联系） | 始终 |
| 3 | 最近更新（RSS 时间轴） | **填写了 RSS 链接才出现，否则整屏隐藏** |
| 4 | 版权 + 次级链接 + 备案 | 始终（留空的字段自动不显示） |

另外：右下角是背景切换胶囊，左下角是背景音乐播放器（没有曲目时隐藏），右侧是分屏指示点。

---

## 一、快速开始

### 方式 A：带后台（推荐）

```bash
python server.py                  # 默认 http://127.0.0.1:8787
python server.py --port 9000      # 换端口
python server.py --host 0.0.0.0   # 对外暴露（先看第七节安全提示）
python server.py --password 新密码 # 忘记密码时重置
```

首次启动会在控制台打印一个随机后台密码，然后：

- 站点：<http://127.0.0.1:8787/>
- 后台：<http://127.0.0.1:8787/admin>

需要 Python 3.8+，**不需要 pip install 任何东西**。

### 方式 B：纯静态（不要后台）

直接把整个目录丢到任意静态托管即可；`index.html` 会读取 `assets/js/config.js` 作为内容。
此时：图片背景、音乐直链仍可用，但**图片上传、RSS 时间轴抓取、网易云代理不可用**（前三者需要服务端）。

## 二、后台能做什么

一个页面，纯表单，没有多余装饰。左侧锚点跳转，底部固定「保存」。

| 区块 | 内容 |
| --- | --- |
| 站点与个人信息 | 站名、姓名、头像字母、身份、一句话、状态、头像（URL 或上传） |
| 社交链接 | 增删改，图标可选 |
| 导航 | 增删改排序，名称 / 副标题 / 链接 / 图标 |
| 底部信息 | 版权、ICP 备案号与跳转、公安备案、次级链接 |
| 背景 | 自动/固定场景、时间表（小时区间 → 场景）、过渡时长、动画开关、**每个场景的图片背景（URL 或上传 + 亮/暗主题覆盖）** |
| 时间轴 | **RSS / Atom 地址列表 + 条数上限 + 抓取预览**（全部留空则首页不出现该屏） |
| 音乐 | 启用开关、自动播放、默认音量、网易云 API 地址、曲目列表（上传文件 / 直链 / 网易云 ID） |
| 上传文件 | 已上传文件列表，可预览、打开、删除 |
| 账号 | 修改密码、退出登录 |

保存后刷新首页即可生效（配置存 `site.json`，静态资源不缓存）。

### 1. 自定义图片背景

在「背景 → 图片背景」里为**指定场景**加一条：填 URL，或点「上传文件」选本地图片。
- 未配图片的场景继续用程序化渐变天空；配了图片就优先用图片（切换场景时交叉淡入）。
- 每条可以指定「主题」：`自动` 表示白天场景用深色文字、其余用亮色文字；如果图片本身很暗/很亮，可强制成 `亮色文字` 或 `暗色文字`，避免看不清。

### 2. RSS 时间轴

在「时间轴」里加订阅源（例如 `https://example.com/feed.xml`），设置最多显示条数，点「抓取预览」确认能抓到。
- 服务端抓取（浏览器直接抓会被 CORS 拦住），支持 RSS 2.0 与 Atom，日期统一成 ISO 再按时间倒序。
- 结果缓存 10 分钟；「抓取预览」会强制刷新。
- **一个源都没填，首页就不会出现这一屏**，指示点也会同步少一个。

### 3. 背景音乐播放器

三种来源，可混用成一个播放列表：

| 类型 | 用法 |
| --- | --- |
| 上传文件 | 在「音乐 → 曲目」里点「上传文件」选 mp3 / m4a / wav / flac 等 |
| 音频直链 | 直接填音频地址（也适用于其他 CDN） |
| 网易云 ID | 填歌曲 ID 或分享链接，点「查询歌曲信息」自动填标题/歌手/封面 |

网易云需要你自己部署一份 [NeteaseCloudMusicApi](https://github.com/Binaryify/NeteaseCloudMusicApi)，把它的地址（如 `http://127.0.0.1:3000`）填到「网易云 API 地址」。
播放时浏览器请求 `/api/music/stream?i=曲目序号`，由服务端解析真实地址后 302 跳转——所以歌曲地址不会写死在页面里，也不会有跨域问题。
注意：受版权限制，部分歌曲可能取不到播放地址，此时播放器会自动跳到下一首。

浏览器策略：默认不允许无交互自动播放。开启「尝试自动播放」后，页面会先试一次，被拦下就等用户的第一次点击/按键再开始；音量与上次播放的曲目记在 `localStorage`。

## 三、设计要求与指标的达成情况

**1. 风格简洁**

- 每屏都是「居中单列 + 玻璃卡片」，没有侧边栏、没有广告位、没有二级菜单。
- 图标一律 1.6px 描边线性风格；分隔线为 1px 渐隐细线；动效只用「淡入 + 上浮」。
- 顶部只留站名（进第二屏后才淡入），其余控件收进底部胶囊与左下角播放器。

**2. 所有控件文字不超过页面的一半**

自检工具（按 `B` 或访问 `?hud=1`）用「占用网格法」统计文字**实际覆盖面积 ÷ 视口面积**（12px 网格去重，重叠不重复计）。实测：

| 视口 | 个人信息 | 导航 | 更新 | 站点信息 | 上限 |
| --- | --- | --- | --- | --- | --- |
| 1440×900 | 2.2% | 1.4% | 2.9%（4 条） | 0.4% | < 50% |
| 390×844 | 6.7% | 3.1% | 随条数增长 | 5.4% | < 50% |

时间轴那一屏随条数与标题长度增长，8 条约 5%，仍远低于上限。
做法上：不写段落、只用短语；窄屏（≤520px）自动隐藏磁贴副标题与来源标签；层级靠**留白和字重**而不是更多文字。

**3. 已按需求移除的占位/说明文本**

`静态构建 · 无跟踪脚本`、`背景随时间变化`、假的 `京ICP备00000000号-1`、示例状态行与示例一句话介绍——全部去掉。
现在的规则是：**留空即不显示**（ICP、公安备案、版权、一句话、状态、副标题、次级链接都是如此），页面上不会出现任何解释性文字。

> 仍保留的示例内容只有「姓名 / 身份 / 导航六项 / 社交三项」，它们是骨架，填一次就替换掉了（都在后台里改）。

## 四、功能：背景按时间自动切换，也能手动切换

- 四套程序化场景（Canvas 实时绘制，不依赖任何图片）：
  `dawn` 清晨 5–8 ｜ `day` 白天 8–17 ｜ `dusk` 黄昏 17–20 ｜ `night` 夜晚 20–5
  （区间在后台「背景 → 时间表」里改，跨夜可把结束写成 29 = 次日 5 点）
- 切换是**数值插值**（天空渐变色标、日月位置/大小/光晕、星尘密度、云带、雾），过渡 1.2 秒，不是硬换图；每 20 秒校验一次时间。
- 手动：底部胶囊里的 ○自动 / 清晨 / 白天 / 黄昏 / 夜晚（纯图标 + `title` 提示）。
- 「白天」自动使用亮色主题（深色文字 + 白色玻璃卡片），其余场景为暗色主题；主题色板随场景一起过渡。
- 首帧前由 `<head>` 内联脚本定好场景与主题，白天访问不会先闪一下夜色。
- 减动效设备（`prefers-reduced-motion: reduce`）只渲染静帧。

## 五、功能：下滑依次展开

- CSS `scroll-snap` + 每屏 `100dvh`，触屏走原生吸附滚动。
- 桌面滚轮「一次滑动 = 一屏」（触控板惯性用 800ms 锁；Firefox 的 `deltaMode` 已归一化）。
- 键盘：`↑ ↓ PageUp PageDown Space Home End`。
- 右侧指示点数量随屏数变化（时间轴未启用时只有三个），第三/四屏有「回到顶部」。
- 无 JS 时降级为普通纵向长页；`prefers-reduced-motion` 下放弃滚轮劫持与动画。

## 六、目录结构

```
index.html                 首页（分屏骨架 + 图标精灵 + 首帧定场景脚本）
admin.html                 后台页面（纯表单，无装饰）
server.py                  后台服务（Python 标准库：静态托管 + 配置 + 上传 + RSS + 音乐代理）
site.default.json          默认内容（开箱值；后台保存的差异写入 site.json）
site.json                  后台实际保存的配置（首次运行自动创建，可为空对象）
admin.json                 后台密码哈希与会话密钥（首次运行生成，600 权限，不会对外提供）
uploads/                   上传的图片 / 音频
assets/css/main.css        首页样式
assets/css/admin.css       后台样式（只做可用性）
assets/js/config.js        离线默认配置（没有后台时用它）
assets/js/background.js    背景引擎（场景插值 / 时间调度 / 手动切换 / 图片背景）
assets/js/music.js         背景音乐播放器
assets/js/app.js           首页运行时（取配置、渲染、分屏滚动、文字占比自检）
assets/js/admin.js         后台逻辑（表单 ↔ site.json）
preview/                   自测脚本与截图（整目录可删）
  ├ _api_test.py               接口自测：登录/上传/RSS/Range/越权 一次跑完
  ├ _mobile.html               用 iframe 造真实 390px 视口，复核窄屏
  ├ _login.html                本机自测登录（?p=密码），用于截图已登录后台
  ├ sample-feed.xml            用于联调时间轴的示例 RSS
  └ *.png                      各场景截图、后台截图
```

`__pycache__/` 是 Python 编译缓存，可安全删除。

## 七、接口与安全

后台接口（除 `/api/site`、`/api/timeline` 外都需要登录 Cookie）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/site` | 当前生效配置（默认值 + site.json 合并结果） |
| GET | `/api/site?full=1` | 同上，需登录（后台用） |
| PUT | `/api/site` | 保存配置（需登录） |
| POST | `/api/login` `/api/logout` `/api/password` | 登录 / 退出 / 改密码 |
| POST | `/api/upload` | 上传（JSON + base64；图片与音频白名单，单文件 ≤32 MB） |
| GET | `/api/uploads` · DELETE `/api/upload?name=` | 列出 / 删除上传文件（需登录） |
| GET | `/api/timeline[?refresh=1]` | 抓取并返回时间轴条目（缓存 10 分钟） |
| GET | `/api/netease/song?id=` | 查歌曲信息（需登录） |
| GET | `/api/music/stream?i=N` | 解析曲目播放地址并 302 |

安全约定：

- 默认只监听 `127.0.0.1`；要用 `--host 0.0.0.0` 对外，请务必先 `--password` 设一个强密码，并在前面加 HTTPS 反向代理。
- 密码只存 `sha256(salt+password)`，登录态是 HMAC 签名、7 天有效的 HttpOnly Cookie；登录失败会延迟 0.4 秒，降低暴力尝试速度。
- `admin.json`、`site.json`、`server.py` 与任何点文件都不可通过 HTTP 读取；静态服务做了目录穿越防护。
- 上传按扩展名白名单 + 随机摘要重命名；音频/图片静态响应支持 `Range`（拖动进度条需要）。
- 后台没有 CSRF token，但依赖 `SameSite=Lax` 的同源 Cookie；如果你要在公网暴露，建议再加一层反代鉴权。

### 自测

```bash
python server.py --password 你的密码       # 另开一个终端启动
python preview/_api_test.py --password 你的密码
```

会依次跑：未登录拦截、登录、传图、传音频、类型白名单、Range、写配置、RSS 抓取与倒序、配置回读、上传列表、敏感文件不可访问。

## 八、常见改法

| 想改什么 | 在哪改 |
| --- | --- |
| 全部文案、导航、备案、背景时间表 | 后台（推荐），或 `site.default.json`（改默认值） |
| 场景配色 / 日月 / 星尘 / 云带 | `assets/js/background.js` 顶部的 `SCENES` |
| 亮色与暗色主题的色值 | `assets/css/main.css` 顶部 `:root` 与 `html[data-theme="light"]` |
| 滚轮灵敏度、翻屏锁定 | 后台无关，改 `assets/js/config.js` 的 `behavior` |
| 时间轴条数、网易云地址 | 后台「时间轴」「音乐」区块（存进 `site.json`） |

## 九、已知边界

- 滚轮「一滑一屏」只对鼠标/触控板启用；触屏与减动效设备走原生吸附滚动，不喜欢可把 `behavior.snapWheel` 置为 `false`。
- 无 JS 时背景为纯深色底，三屏内容照常可读；无后台时时间轴不显示。
- 网易云曲目受版权与登录限制，取不到地址时会自动跳过，并在后台查询时给出提示。
- 程序化天空是抽象风格（渐变 + 日月 + 星尘 + 云带）；要写实就上传自己的图片。
- 后台表单一次保存整份配置（`PUT` 合并写入）；列表内的增删会整体替换该列表。
